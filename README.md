# Variant-Analysis-for-HBB-Gene

This repository contains a **FASTA file** comprising the coding sequence (CDS) of *human haemoglobin subunit beta (HBB)*, and it is used as an input for an object-oriented Python pipeline that uses **Biopython** (Entrez, SeqIO, Seq, ProtParam) and **Pandas** to retrieve and process a human HBB reference sequence, introduce 12 nucleotide **variants** (substitutions, insertions, and deletions), and analyse their **effects on protein translation.**
